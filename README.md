# Employee Management System (SQL Project)

## 📌 Objective
Analyze employee data using SQL queries.

## 📊 Tables Used
- Employees
- Departments
- Attendance

## 🔍 Key Analysis
- Salary analysis
- Department-wise insights
- Attendance tracking

## 🛠 Skills Used
- SQL Joins
- Aggregation (GROUP BY)
- Subqueries
- Window Functions (ROW_NUMBER)

## 📈 Insights
- IT department has highest salaries
- Some employees show frequent absence patterns
